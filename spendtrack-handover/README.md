# SpendTrack development handover
Start with `docs/PRODUCT.md` for behavior, `docs/TECHNICAL.md` for architecture, `docs/DECISIONS.md` for frozen decisions, `docs/ROADMAP.md` for phases, and `docs/TEST_CASES.md` for acceptance tests. `AGENTS.md` contains instructions for AI coding assistants.
